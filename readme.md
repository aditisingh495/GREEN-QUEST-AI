🌿 GreenQuest — Less Scrolling. More Sky.
GreenQuest is a web app that encourages people to spend less time scrolling and more time exploring the outdoors. It turns free time into simple outdoor quests based on your available time, energy level, and interests.
✨ Features
- 🌱 Discover fun outdoor activities and mini-adventures
- ⏱️ Choose quests based on the time you have
- ⚡ Match activities to your energy level and interests
- 🌳 Encourage screen-time balance and reconnect with nature
- 💻 Simple, responsive interface built for the web
🛠️ Built With
- HTML
- CSS
- JavaScript
🚀 Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
No build tools are required for the basic HTML, CSS, and JavaScript version.
🎯 Mission
Help people step away from their screens, explore their surroundings, and make everyday outdoor moments count.
🌍 Why GreenQuest?
Technology should support a healthy life—not keep us indoors all day. GreenQuest uses a simple, playful web experience to make choosing an outdoor activity easier.
